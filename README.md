# Restaurant Menu Ordering System 🍽️

## 📌 Project Description
This is a beginner-friendly Python program that simulates a restaurant menu ordering system.
Users can:
- View a predefined menu
- Select food items
- Place multiple orders
- View the total bill amount

This project is created to practice Python basics like dictionaries, loops, conditionals, and user input.

## 🛠️ Technologies Used
- Python
